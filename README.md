# Rusman Launcher

Офлайн-лаунчер Minecraft для Windows.

## Скачать

Актуальная сборка — на странице [Releases](https://github.com/PatronRusMan/rusman-launcher/releases).

1. Скачай `RusmanLauncher-*-win-x64.zip`
2. Распакуй
3. Запусти `Rusman Launcher.exe`

Лаунчер умеет обновляться сам: **Настройки → Проверить обновление**.

## Важно

В этом репозитории **нет исходного кода** — только описание и релизы готовых сборок.
